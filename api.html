BTD6 API

Access Ninja Kiwi's BTD6 Open Data API directly from BTD6 Tools. Your OAK/API key is saved locally on this device.

🔑 API Key

Enter your Ninja Kiwi Open Access Key (OAK). The key is stored only in this browser's local storage and is shared between the API tools.

```
No key saved
Privacy: BTD6 Tools does not send your API key anywhere except Ninja Kiwi's API requests. It is stored using your browser's localStorage so it remains available when you reopen the PWA.
```

👤 Players

Look up player information and retrieve save data associated with an OAK.

```

Player Lookup

GET /btd6/users/:userID

Save Data

GET /btd6/save/:oakID
```

🏁 Races

View races, race metadata, and race leaderboards.

```

All Races

GET /btd6/races

Race Metadata

GET /btd6/races/:raceID/metadata

Race Leaderboard

GET /btd6/races/:raceID/leaderboard
```

👹 Bosses

Access boss events, metadata, and boss leaderboards.

```

All Bosses

GET /btd6/bosses

Boss Metadata

GET /btd6/bosses/:bossID/metadata/:difficulty

Boss Leaderboard

GET /btd6/bosses/:bossID/leaderboard/:type/:teamSize
```

🗺️ Maps

Browse BTD6 maps, filter maps, or retrieve a specific map.

```

All Maps

GET /btd6/maps

Filter Maps

GET /btd6/maps/filter/:mapFilter

Specific Map

GET /btd6/maps/map/:mapID
```

🎯 Challenges

Browse challenges, filter them, or retrieve an individual challenge.

```

All Challenges

GET /btd6/challenges

Filter Challenges

GET /btd6/challenges/filter/:challengeFilter

Specific Challenge

GET /btd6/challenges/challenge/:challengeID
```

🌎 Contested Territory

View CT information, tiles, and the different CT leaderboards.

```

Current CT

GET /btd6/ct

CT Tiles

GET /btd6/ct/:ctID/tiles

Player Leaderboard

GET /btd6/ct/:ctID/leaderboard/player

Team Leaderboard

GET /btd6/ct/:ctID/leaderboard/team

Group Leaderboard

GET /btd6/ct/:ctID/leaderboard/group/:groupID
```

👥 Guild

Guild Lookup

```
